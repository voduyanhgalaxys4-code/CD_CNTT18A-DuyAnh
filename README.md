1.CÁCH CHẠY

Bước 1: Mở Visual Studio Code (VS Code).

Bước 2: Chọn File → Open Folder, mở thư mục CD_CNTT18A-DuyAnh chứa tập tin hello.js.

Bước 3: Mở Terminal → New Terminal để mở cửa sổ dòng lệnh.

Bước 4: Tạo tập tin hello.js bằng Notepad.

Nhập lệnh sau trong Terminal:

notepad hello.js

<img width="437" height="37" alt="image" src="https://github.com/user-attachments/assets/fb107aab-f6a2-4737-bace-9c3f1b9c1663" />

Nếu xuất hiện thông báo tạo file mới, chọn Yes.

Nhập nội dung chương trình:

console.log("Hello Node.js");

Bước 5: Kiểm tra phiên bản Node.js bằng lệnh:

node -v

Kết quả: v26.13.0.

<img width="195" height="61" alt="image" src="https://github.com/user-attachments/assets/98279ad0-b6cf-4df7-9bf3-7aae18c035b3" />

Bước 6: Kiểm tra phiên bản npm bằng lệnh:

npm -v

Kết quả: 11.20.0.

<img width="193" height="53" alt="image" src="https://github.com/user-attachments/assets/4c767b69-4a08-43ad-b4e0-5b46e2634e31" />

Bước 7: Nhập lệnh sau để chạy chương trình:

node hello.js

2.MÔ TẢ KẾT QUẢ THỰC HIỆN

Node.js được cài đặt thành công với phiên bản v26.13.0.

npm được cài đặt thành công với phiên bản 11.20.0.

Tập tin hello.js được tạo thành công bằng Notepad.

Chương trình được thực thi thành công bằng lệnh node hello.js.

Hàm console.log() hiển thị nội dung Hello Node.js trên Terminal.
