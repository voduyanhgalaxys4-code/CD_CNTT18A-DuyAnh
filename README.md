Node.js: Sau khi chạy lệnh node -v, màn hình hiển thị phiên bản v26.13.0, chứng tỏ Node.js đã được cài đặt và có thể sử dụng.

npm: Sau khi chạy lệnh npm -v, màn hình hiển thị phiên bản 11.20.0, chứng tỏ npm đã được cài đặt thành công.

Tập tin hello.js: Đã tạo tập tin JavaScript chứa hai câu lệnh console.log().

Kết quả thực thi: Khi chạy lệnh node hello.js, chương trình hiển thị hai dòng chữ trên CMD. Điều này chứng tỏ Node.js đã thực thi thành công tập tin JavaScript.
