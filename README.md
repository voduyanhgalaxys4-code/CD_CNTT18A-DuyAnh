1.CÁCH CHẠY

Bước 1: Mở Visual Studio Code (VS Code).

Bước 2: Chọn File → Open Folder, mở thư mục nodejs-bai1 chứa tập tin hello.js.

Bước 3: Mở Terminal → New Terminal để mở cửa sổ dòng lệnh.

Bước 4: Kiểm tra phiên bản Node.js bằng lệnh:

node -v

Kết quả: v26.13.0.

<img width="195" height="61" alt="image" src="https://github.com/user-attachments/assets/98279ad0-b6cf-4df7-9bf3-7aae18c035b3" />

Bước 5: Kiểm tra phiên bản npm bằng lệnh:

npm -v

Kết quả: 11.20.0.

<img width="193" height="53" alt="image" src="https://github.com/user-attachments/assets/4c767b69-4a08-43ad-b4e0-5b46e2634e31" />


Bước 6: Nhập lệnh sau để chạy chương trình:

node hello.js

2.KẾT QUẢ THỰC HIỆN

Sau khi chạy lệnh node hello.js, Terminal hiển thị kết quả:

Hello Node.js
